# MATH012 ALEKS Homwork reminder | WhatsApp bot

Basically, I'm taking MATH012 at uni, and every week, we have an online homwork on ALEKS

the thing is, EVERYBODY forgets that homework exists

so, I made this WhatsApp bot that sends a message a day before the deadline to remind everyone to do their homework

Making this bot helped me learn how to deal with API, .env files, how to hide files from git using .gitignore,
 and learn about a couple libraries like schedule and requests

You can consider this my first REAL small project to fix a REAL issue we have,
 rather than some random script that'll end up being accidentally deleted off my computer someday
